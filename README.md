# aifacesearch.net

Public product guide for [aifacesearch.net](https://aifacesearch.net/), a photo-based face search service for exploring possible visual matches and their source pages.

This repository contains documentation, not the application's source code. It is maintained by the product's developer.

## How it works

1. Choose a clear photo of one person that you own or are authorized to use.
2. Check the local preview. Selecting a photo does not run a real search.
3. Sign in, review the current pricing and obtain credits if needed.
4. Explicitly confirm a search. Each real search uses one credit; buying credits does not start a search automatically.
5. Review possible matches and open their source pages for context.

## Preview, payment and results

| Stage | What to expect |
| --- | --- |
| Local preview | A chance to check the selected image; it is not a free search or a set of discovered matches. |
| Real search | Requires sign-in, available credits, an available search service and explicit confirmation. |
| Results | Possible visual matches and source links. A search can also return no results. |

## Interpreting a match

A similarity score measures visual resemblance, not the probability that two photos show the same person. Check the original page and independent context before drawing conclusions. A reused photo does not establish who controls an account, and no results does not prove that an image has never appeared elsewhere.

Use a simple private review checklist:

- Record the source URL and the date you checked it.
- Separate what the page visibly shows from what you infer.
- Check for copied images, outdated pages and misleading context.
- Avoid accusations or consequential decisions about a person based only on a match.
- If your own image is being misused, follow the relevant platform's reporting process.

## Privacy and support

Use only photos you have the right to search. Review the service's current privacy information, terms and pricing on the [official website](https://aifacesearch.net/) before starting a paid search.

Please do not upload face photos, private source URLs, account details or other personal information to GitHub issues. For account or billing questions, use the contact information on the official site.
